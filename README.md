# Лапша — браузерная 3D-игра

Реализация концепта из «ТЗ.pdf». Браузерная платформа подтверждена в переписке.

## Запуск

На Windows дважды нажмите **Start-Game.cmd**. Он запустит готовую сборку на локальном сервере и откроет браузер. На этом компьютере Node.js уже установлен; npm install для игры не нужен. Интернет во время игры не требуется.

На другом компьютере нужен Node.js 20.19+ либо 22.12+ (для разработки). Для готовой сборки достаточно современной версии Node.js. Вручную: `node serve.cjs`, затем открыть http://127.0.0.1:5173/. Сохранения привязаны к адресу браузера; запускайте игру по одному и тому же адресу.

Файл `dist/index.html` нужно открывать через HTTP, а не двойным нажатием: браузер ограничивает загрузку модулей по file://. Для размещения на статическом хостинге достаточно содержимого `dist/`.

## Как играть

- Зажмите мышь или коснитесь экрана и проведите поперёк провода. Разрез происходит в месте пересечения.
- Отрезок падает и остаётся на полу. Через 3 секунды после касания начинается сгорание с искрами длительностью 0,8 секунды; затем начисляются монеты. Неразрезанный провод продолжает спускаться и складывается внизу.
- Корзина открывает магазин. Некупленная колба открывает карточку покупки. Покупка сразу добавляет материал в ротацию. Нажатие на купленную колбу переключает «Выбрать / Выбран» бесплатно: можно включить несколько материалов одновременно.
- Выбранные материалы идут по очереди в новые источники и новые участки провода. После разреза источник берёт следующий материал из ротации. Уже выпущенные участки не перекрашиваются, их стоимость сохраняется. Если убрать все материалы, подача приостанавливается до выбора хотя бы одного.
- Когда плотная куча достигает верхней границы, все источники временно прекращают подачу. После разрезания и снижения кучи подача возобновляется автоматически.
- Ускорение подачи увеличивает скорость на 30% от базовой за уровень и не имеет максимального уровня. Начальная цена — 180 монет, каждый следующий уровень дороже в 2,5 раза.
- В магазине и карточке материала есть покупка дополнительных проводов без фиксированного ограничения количества. Второй стоит 300, третий 1200, четвёртый 3600, пятый 9000 монет. Далее цена следующего источника равна `600 × текущее_количество²`. Покупка источника и включение материала в ротацию — разные действия.
- Звук включается кнопкой сверху. Кнопка Ⅱ ставит игру на паузу. Escape закрывает магазин или переключает паузу.

## Что реализовано

- Three.js / WebGL: объёмные провода, стеклянные колбы, пробки, цветные материалы, освещение и движущиеся блики; голографический материал использует iridescence. Сечение игрового провода использует 6 граней и автоматически снижается до 5 или 4 при больших кучах.
- Провод состоит из физических узлов с ограничениями длины и изгиба. Фиксированный шаг 1/120 секунды, гравитация и столкновения с полом, стенками и другими участками провода в ограниченном по глубине 3D-пространстве. Физическая глубина сцены уменьшена вдвое до `±0.29`. Контакты между проводами имеют умеренное касательное трение: оно удерживает слои друг на друге, поэтому куча быстрее набирает высоту и меньше растекается. У пола также есть трение. Нижние контактные участки получают повышенную эффективную массу, а их скорость гасится пропорционально давлению и удалению от начала провода. Длинный неразрезанный провод постепенно запекает успокоившийся дальний хвост: эти узлы выходят из интеграции и решателя ограничений, но остаются неподвижной коллизионной оболочкой. При разрезании они размораживаются. Это снижает работу без дыр и проваливания проводов. При высокой плотности столкновения продолжают проверяться несколько раз за шаг решателя. Вертикальные нити в зоне выдачи не сталкиваются друг с другом, поэтому множество источников не образует пробку у сопел; ниже сохраняется полная физика кучи. За один кадр выполняется не более четырёх шагов: при перегрузе симуляция плавно замедляется вместо нестабильного «кипения». Пространственная сетка столкновений и рендер-буферы переиспользуются. Broad phase сначала собирает узлы по ячейкам, затем единожды проверяет пары внутри ячейки и только 13 направлений соседства вместо 27 поисков для каждого узла. Источники размещаются в несколько рядов по глубине, чтобы поддерживать большое количество одновременно.
- Второй источник и отрезанные от него фрагменты экспериментально используют электрический FBM-шейдер, адаптированный с [Shadertoy ldlXRS](https://www.shadertoy.com/view/ldlXRS) на UV-развёртку трубы. Быстрый общий строб отключён, по длине проходит одна медленная световая волна.
- В глобальном выборе вида доступен анимированный шейдер жидкого металла, адаптированный с [Shadertoy Molten II (DdyGDD)](https://www.shadertoy.com/view/DdyGDD). Рисунок замкнут вокруг трубы без заметного UV-шва, а число итераций уменьшено для работы на больших кучах.
- Там же доступна «Хроматическая плазма» — бесшовная адаптация шейдера randy read (rcread, 2015), основанного на [Shadertoy MtjXzc](https://www.shadertoy.com/view/MtjXzc) и распространяемого по лицензии [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/). Крупный рисунок движется вдоль провода, а не поперёк него.
- Каждый отдельный провод получает собственное постоянное смещение времени, поэтому анимированные шейдеры не пульсируют синхронно.
- Свайп может пересечь несколько витков. Деление сохраняет суммарную длину. Отрезки сохраняют исходный материал при смене выбранного провода.
- После падения отрезки продолжают участвовать в физике. Награда выдаётся один раз после завершения сгорания. Доход зависит от длины и материала.
- Шесть материалов с множителями ×1, ×2, ×4, ×7, ×12, ×20. Цены 0, 120, 420, 1200, 3200 и 6000 выбраны для играбельной прогрессии; одинаковые ценники 6000 в макете использованы как визуальный референс.
- Игровая рамка сохраняет соотношение **1320 × 2868**. За пределами рамки — чёрный цвет. Синий фон заполняет рамку. Внутреннее разрешение рендера адаптируется к устройству, DPR ограничен 2.
- Оригинальные фон и иконки из Figma хранятся локально. Колбы воссозданы геометрией, чтобы соответствовать требованию 3D; это не точные исходные модели Figma. Шрифт заменён системным Arial, потому что файл Proxima Nova в ТЗ не приложен.
- Монеты, покупки, выбранная ротация, количество проводов, улучшения, счётчик разрезов и звук сохраняются в localStorage. Кнопка «Сброс» в верхней панели удаляет весь прогресс после подтверждения. Сохранения предыдущей версии автоматически получают ротацию из ранее выбранного материала. Геометрия лежащих проводов не сохраняется: при перезагрузке начинается новая сцена с прежним банком и покупками.

Магазин и карточки материалов не останавливают физику: лапша продолжает подаваться, пока открыты эти экраны. Ручная пауза и скрытая вкладка приостанавливают физику; офлайн-доход не начисляется. Фиксированного лимита физических узлов нет, но достижение кучей верхней границы временно блокирует новые сегменты до расчистки. Детектор использует контактные узлы, задержку и разные пороги остановки/возобновления, поэтому свободно висящие нити и колебания у границы не вызывают ложных переключений.

Кнопка «Физика» открывает компактную регулируемую по высоте верхнюю панель. В ней оставлены десять наиболее заметных настроек: скорость и количество проводов, толщина, гравитация, колебание, изгиб, оба трения, ширина и глубина сцены. Глобальный список «Вид всех проводов» позволяет применить любой игровой материал или один из трёх анимированных шейдеров ко всей лапше. Значения и выбранный вид автоматически сохраняются отдельно от прогресса; кнопка «По умолчанию» сбрасывает настройки и возвращает купленное количество проводов.

## Разработка

```sh
npm ci
npm run dev
npm test
npm run build
```

`src/physics.js` — физика и разрезы. `src/economy.js` — материалы, покупки и валидация сохранений. `src/scene.js` — рендер и модели. `src/main.js` — игровой цикл, ввод и интерфейс. `src/style.css` — адаптивная рамка и интерфейс.
